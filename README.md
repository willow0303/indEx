# indEx – Online Grading System

indEx is a web-based Online Grading and Academic Management System designed to help teachers and students manage courses, grades, attendance, and academic records efficiently. This system is developed for Pampanga State University – College of Computing Studies.

------------------------------------------------------------

SYSTEM ACCESS

After setup, access the system using:
http://localhost/online-grading-system/index.php

------------------------------------------------------------

TEACHER INVITATION CODE

Use this invitation code during Teacher registration:
PSU-indEx2025

------------------------------------------------------------

SYSTEM REQUIREMENTS

- XAMPP 
- PHP 
- MySQL / MariaDB
- Web Browser (Chrome, Edge, Firefox)
- Internet connection

------------------------------------------------------------

INSTALLATION GUIDE

STEP 1: DOWNLOAD THE PROJECT
1. Download or clone the project.
2. Extract the project folder.
3. Move the folder to:
   - XAMPP: htdocs
4. Folder name must be:
   online-grading-system
5. Make sure that there is only one project folder to avoid path file errors.

------------------------------------------------------------

STEP 2: DOWNLOAD THE DATABASE
1. Download the database from Google Drive.
2. The database file is located inside the folder:
   /Database
3. Database filename:
   online_grading_system.sql

------------------------------------------------------------

STEP 3: IMPORT THE DATABASE
1. Open:
   http://localhost/phpmyadmin
2. Click New.
3. Database name:
   online_grading_system
4. Click Create.
5. Select the database.
6. Click Import.
7. Choose:
   online_grading_system.sql
8. Click Go.

------------------------------------------------------------

STEP 4: RUN THE SYSTEM

Open in browser:
http://localhost/online-grading-system/index.php

You may now:
- Register as Student
- Register as Teacher using the invitation code:
  PSU-indEx2025
